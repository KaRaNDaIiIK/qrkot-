# QRKot - Благотворительный фонд поддержки котиков

# Описание проекта
Проект QRKot представляет собой API для благотворительного фонда, собирающего пожертвования на целевые проекты помощи кошкам. Пользователи могут создавать проекты с указанием требуемой суммы, делать пожертвования, которые автоматически распределяются по открытым проектам по принципу FIFO (первый открытый — первый получает).

## Особенности проекта
- Регистрация и аутентификация пользователей (JWT)
- Разграничение прав доступа (пользователь / суперпользователь)
- Создание целевых проектов с указанием названия, описания и требуемой суммы
- Автоматическое распределение пожертвований по открытым проектам
- Принцип FIFO при распределении средств
- Автоматическое закрытие проектов при достижении требуемой суммы
- Частичное обновление проектов (PATCH)
- Удаление только незакрытых проектов без инвестиций
- Автоматическая валидация входных данных
- Интеграция с Google Sheets API для формирования отчетов
- Автоматическое создание отчетов о скорости закрытия проектов
- Документация API через Swagger и ReDoc

## Технические особенности проекта
- Асинхронное API на FastAPI
- SQLAlchemy 2.0 с асинхронным доступом к БД
- Миграции базы данных через Alembic
- Валидация данных через Pydantic
- Аутентификация через FastAPI Users (JWT)
- DRY-принцип в CRUD-операциях
- Модульная архитектура проекта
- Интеграция с Google Sheets API (aiogoogle)

## Аутентификация
Регистрация: POST /auth/register
Получение токена: POST /auth/jwt/login
Доступ к защищённым эндпоинтам: Authorization: Bearer <token>

## Основные эндпоинты
POST /charity_project/ — создать новый проект
GET /charity_project/ — получить список всех проектов
PATCH /charity_project/{id} — обновить проект
DELETE /charity_project/{id} — удалить проект
POST /donation/ — сделать пожертвование
GET /donation/ — получить список всех пожертвований

## Права доступа
Роль	Права
---
Аноним	Просмотр списка проектов, регистрация
Пользователь	Просмотр проектов, создание пожертвований, просмотр своих пожертвований
Суперпользователь	Всё из пользователя + создание/обновление/удаление проектов, просмотр всех пожертвований

## Настройки и константы
- Константы проекта хранятся в файле .env или в app/core/config.py.
- APP_TITLE — название приложения (по умолчанию "Благотворительный фонд поддержки котиков QRKot")
- DESCRIPTION — описание API
- DATABASE_URL — URL подключения к базе данных (по умолчанию "sqlite+aiosqlite:///./fastapi.db")
- SECRET	Секретный ключ для JWT
- FIRST_SUPERUSER_EMAIL	Email первого суперпользователя
- FIRST_SUPERUSER_PASSWORD	Пароль первого суперпользователя

## Google Sheets настройки
- SPREADSHEET_ID — ID существующей Google таблицы
- SHEET_NAME — имя листа в таблице (по умолчанию "Отчет")
- EMAIL — email для выдачи прав доступа к таблице
- Данные сервисного аккаунта (TYPE, PROJECT_ID, PRIVATE_KEY, CLIENT_EMAIL и др.)
